# Portfólio — Gabriel Oliveira

Portfólio profissional desenvolvido com React e Vite, reunindo projetos de tecnologia, pesquisa aplicada e modelos gerenciais em Excel voltados a Administração, Finanças e Ciências Contábeis.

## Destaques

- Apresentação profissional com tema claro/escuro e navegação responsiva.
- Projetos web e acadêmicos com descrição de contexto, tecnologias e entregáveis.
- Coleção de oito modelos de Excel, organizados por área de aplicação.
- Filtros por categoria para facilitar a navegação pelas planilhas.
- Currículo em PDF e canais de contato direto.

## Modelos de Excel

| Modelo | Aplicação principal |
|---|---|
| Controle Financeiro | Lançamentos, receitas, despesas e saldo |
| Contas a Pagar e Receber | Vencimentos, atrasos e valores em aberto |
| Controle de Estoque | Saldo, custo unitário e reposição |
| Fluxo de Caixa | Entradas, saídas e saldo acumulado |
| Dashboard Gerencial | KPIs, metas, resultado e margem |
| DRE Gerencial | Formação do resultado e análise de margens |
| Orçamento x Realizado | Desvios e acompanhamento mensal |
| Custos e Formação de Preço | Custo unitário, margem e preço sugerido |

Os arquivos incluem uma aba **Comece aqui**, campos editáveis destacados, fórmulas automáticas, filtros e validações quando aplicável. Os dados são fictícios e servem apenas para demonstração. Antes de qualquer uso operacional, substitua os exemplos e valide premissas e critérios com a área responsável. Os modelos gerenciais não substituem escrituração, demonstrações contábeis oficiais ou orientação profissional.
