# Portfólio — Gabriel Oliveira

Portfólio desenvolvido com React e Vite, com projetos de tecnologia e uma seção de modelos de planilhas voltados a Administração, Finanças e Ciências Contábeis.

## Planilhas disponíveis

- Controle Financeiro
- Contas a Pagar e Receber
- Controle de Estoque
- Fluxo de Caixa (lançamentos, saldo acumulado e gráfico)
- Dashboard Gerencial (KPIs, metas e base mensal)
- DRE Gerencial (resultado e margens)
- Orçamento x Realizado (desvios e acompanhamento)
- Custos e Formação de Preço (custo unitário e preço sugerido)

Os arquivos novos contêm fórmulas, formatação e dados fictícios para demonstração. Antes de usar em uma operação real, substitua os exemplos e valide os critérios com a área responsável. Os modelos são gerenciais e não substituem escrituração ou demonstrações contábeis oficiais.

## Executar localmente

```bash
npm install
npm run dev
```

## Gerar build

```bash
npm run build
```
